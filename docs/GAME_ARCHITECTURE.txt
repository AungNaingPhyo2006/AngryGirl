1. အကျဉ်းချုပ်
--------------------------------------------------------------------------------

Angry Girl က 2D endless runner game ပါ။ Player (code ထဲမှာ "Ninja") က
ဘယ်ဘက်မှာ နေရာမပြောင်းဘဲ ပြေးနေပြီး နောက်ခံ (parallax) နဲ့ ရန်သူ၊ စိန်၊
power-up တွေက ညာဘက်ကနေ ဘယ်ဘက်ကို ရွေ့လာပါတယ်။

  - Screen ကို နှိပ်ရင် ခုန်တယ် (လေထဲမှာ တစ်ခါ ထပ်ခုန်လို့ရတယ်)
  - ကန်လို့ရတဲ့ ရန်သူကို ဝင်တိုက်ရင် ကန်ပြီး ရမှတ်ရတယ်
  - ကန်လို့မရတဲ့ ရန်သူကို ကျော်ခုန် (သို့) ဒုံးကျည်/bomb နဲ့ ပစ်ရတယ်
  - စိန်တွေ စုပြီး Shop မှာ upgrade၊ skin စတာတွေ ဝယ်လို့ရတယ်

Game ကို အပိုင်း ၂ ပိုင်း ခွဲထားပါတယ် —
  (က) Flame အပိုင်း  : Game world ထဲက character၊ ရန်သူ၊ collision၊ animation
  (ခ) Flutter အပိုင်း : Menu၊ HUD၊ Shop စတဲ့ UI တွေ (Flame "overlay" အဖြစ်)

4. App စတင်ပုံ (main.dart)
--------------------------------------------------------------------------------

  main()
   │
   ├─ WidgetsFlutterBinding.ensureInitialized()
   │     Hive နဲ့ Flame က platform channel သုံးလို့ အရင်ခေါ်ရတယ်
   │
   ├─ initHive()
   │     - Hive.init(documents folder)          (web မှာတော့ မလိုပါ)
   │     - PlayerDataAdapter, SettingsAdapter ကို register လုပ်တယ်
   │
   └─ runApp(NinjaRunApp())
         MaterialApp → Scaffold → GameWidget<NinjaRun>.controlled(...)

  GameWidget ထဲမှာ —
    - gameFactory      : NinjaRun ကို CameraComponent.withFixedResolution(360x180)
                         နဲ့ ဆောက်တယ်။ Screen အရွယ် ဘယ်လိုပဲ ဖြစ်ဖြစ် game ထဲမှာ
                         360x180 coordinate ပဲ သုံးတယ်။
    - overlayBuilderMap: Overlay id → Widget ကို register လုပ်ထားတယ်
    - initialActiveOverlays: [MainMenu.id] - ဖွင့်ဖွင့်ချင်း Main menu ပြတယ်
    - loadingBuilder   : NinjaRun.onLoad() မပြီးခင် loading bar ပြတယ်

  Overlay တိုင်းကို _withLanguage() နဲ့ ထုပ်ထားတယ် —
    - game load မပြီးသေးရင် ဘာမှ မပြဘူး (settings မရှိသေးလို့)
    - Settings ပြောင်းရင် overlay ကို rebuild လုပ်တယ် (ListenableBuilder)
    - မြန်မာစာ ရွေးထားရင် စာလုံးကို 0.85 ဆ သေးအောင် လုပ်တယ်
      (မြန်မာစာလုံးက English ထက် အမြင့် ပိုလိုလို့)

7. Flame Game Tree (Component များ)
--------------------------------------------------------------------------------

  NinjaRun (FlameGame, TapCallbacks, HasCollisionDetection)
  ├── camera (CameraComponent, fixed 360x180)
  │   └── backdrop
  │       └── ParallaxComponent         ← နောက်ခံ အလွှာများ (applyBackground)
  │
  └── world
      ├── Ninja                         ← player
      ├── EnemyManager                  ← ရန်သူ spawn (timer + milestone)
      ├── CollectibleManager            ← စိန်၊ power-up၊ bat item spawn
      ├── HelperDinoSpawner             ← dino spawn
      ├── TutorialManager               ← tutorial ကစားမှသာ
      │
      │   (ကစားရင်း ထပ်ဝင်လာ/ထွက်သွားတဲ့ component များ)
      ├── Enemy × n
      ├── Diamond × n
      ├── PowerUpItem / HelperBatItem
      ├── HelperDino / HelperBat
      ├── Rocket × n, Bomb × n, Explosion × n
      ├── Fireball × n, EnemyRocket × n
      └── ScorePopup × n

  Manager တွေက ကိုယ်တိုင် မဆွဲပါဘူး။ update() ထဲမှာ timer/ရမှတ်ကို စစ်ပြီး
  world ထဲကို component အသစ် add လုပ်ပေးရုံပါ။

  Component တွေက HasGameReference<NinjaRun> mixin သုံးလို့ `game.` နဲ့
  playerData၊ settings၊ ninja၊ virtualSize တွေကို ယူသုံးလို့ရတယ်။

  Coordinate: (0,0) က ဘယ်ဘက်အပေါ်ထောင့်၊ virtualSize = (360, 180)။
  မြေပြင်က y ≈ 164 (virtualSize.y - 16)။ Ninja က x = 32 မှာ ပြေးတယ်။

8. Game Loop နဲ့ အဓိက Function များ
--------------------------------------------------------------------------------

8.1 Flame ရဲ့ lifecycle

  onLoad()   Component ကို ပထမဆုံး load လုပ်ချိန် တစ်ခါပဲ (ပုံ load စသည်)
  onMount()  World ထဲ ရောက်တိုင်း (restart မှာလည်း ပြန်ခေါ်တယ်)
  update(dt) Frame တိုင်း။ dt = ပြီးခဲ့တဲ့ frame ကနေ ကြာတဲ့ စက္ကန့်
  render()   Frame တိုင်း ဆွဲတယ်
  onCollision / onCollisionStart  Hitbox ချင်း ထိရင်

  ရွေ့လျားမှုတွေကို "speed * dt" နဲ့ တွက်လို့ ဖုန်းမြန်/နှေး မတူလည်း
  အရှိန် တူပါတယ်။

8.2 NinjaRun (lib/game/ninja_run.dart) - main game class

  onLoad()
    - Full screen + landscape ထားတယ်
    - Hive ကနေ PlayerData နဲ့ Settings ကို ဖတ်တယ် (မရှိရင် အသစ်ဆောက်)
    - AudioManager.init() + BGM စဖွင့်တယ်
    - ပုံအားလုံးကို images.loadAll() နဲ့ cache လုပ်တယ်
    - applyBackground() - shop မှာ ရွေးထားတဲ့ နောက်ခံကို ထည့်တယ်

  startGamePlay()     ပုံမှန်ဂိမ်း စတယ်
    - lives = maxLives, revives = 0
    - startShield upgrade ရှိရင် ဒိုင်းနဲ့ စတယ်
    - One-game item ဝယ်ထားရင် သုံးတယ် (ဒုံးကျည် ၃၊ x2၊ burst ၂)
    - Ninja, EnemyManager, CollectibleManager, HelperDinoSpawner ကို add
    - _showHudGuideIfNew()

  startTutorial()     Tutorial စတယ်
    - စိန်နဲ့ highScore ကို _beforeTutorial ထဲ မှတ်ထားတယ်
    - Ninja, EnemyManager(autoSpawn: false), TutorialManager ကို add

  restart()           Tutorial ဆို tutorial၊ မဟုတ်ရင် ပုံမှန်ဂိမ်း ပြန်စတယ်

  reset()             World ကို ရှင်းပြီး ကစားစဉ် data တွေ 0 ပြန်ထားတယ်
    - world.removeAll(world.children)
    - score, rockets, bursts, shield, magnet, x2, carry = 0
    - Tutorial ဖြစ်ခဲ့ရင် စိန်နဲ့ highScore ကို မူလအတိုင်း ပြန်ထားတယ်

  revive()            စိန်ပေးပြီး အသက် ၁ ခုနဲ့ ဆက်ကစားတယ်
    - ရန်သူ၊ မီးလုံး၊ ရန်သူဒုံးကျည်တွေကို ရှင်းတယ်
    - ninja.recover() (ခဏ မထိခိုက်အောင်)

  fireRocket()        rockets ရှိရင် ၁ ခု လျော့ပြီး Rocket ကို ninja ရှေ့က ပစ်တယ်

  dropBombs()         bursts ရှိရင် ninja ရှေ့က screen ထဲရှိ အနီးဆုံး ရန်သူ
                      ၂ ကောင်ပေါ် Bomb ချတယ်။ ရန်သူမရှိရင် burst မကုန်ဘူး။

  update(dt)          lives <= 0 ဆိုရင် GameOverMenu ပြပြီး pause လုပ်တယ်

  onTapDown()         Hud ပြနေရင် (= ကစားနေရင်) ninja.jump()

  lifecycleStateChange()  App background/foreground ဖြစ်ရင် pause/resume

8.3 Ninja (lib/game/ninja.dart)

  Animation state များ (NinjaAnimationStates)
    run     ပြေးနေတယ်
    idle    ခုန်နေတယ် (jump() မှာ သုံးတယ်)
    kick    ရန်သူကို ကန်နေတယ်
    hit     ထိခိုက်ခံရတယ်
    sprint  (မသုံးသေး)
    carried လင်းနို့ ချီထားတယ် - Warrior_Jump_1~3.png

  update(dt)
    - Carried ဆိုရင် _updateCarried(): ရှေ့နဲ့ အပေါ်ကို ရွေ့၊ carryTime လျော့
    - မဟုတ်ရင် gravity: speedY += 800*dt; y += speedY*dt
      ရှေ့ရောက်နေရင် _homeX (32) ကို ဖြည်းဖြည်း ပြန်လာတယ်
    - မြေပြင်ရောက်ရင် y = yMax, run animation
    - timer တွေ (hit, attack, shield) နဲ့ magnet/x2 အချိန်ကို လျော့တယ်

  jump()        မြေပြင်ကနေ (သို့) လေထဲမှာ တစ်ခါထပ် (max 2) speedY = -300
  onCollision() Enemy နဲ့ထိရင် —
                  attackable ဆိုရင် attack() → ကန်ပြီး ရမှတ်ယူ
                  မဟုတ်ရင် ဒိုင်းရှိရင် _blockWithShield()၊ မရှိရင် hit()
                  Carried ဖြစ်နေရင် ဘာမှ မလုပ်ဘူး
  hit(damage)   lives -= damage, hit animation
  hitByProjectile(damage)  မီးလုံး (0.5) / ရန်သူဒုံးကျည် (1)
  recover()     revive ပြီး ခဏ မထိခိုက်အောင် _shieldTimer ကို စတယ်

8.4 Enemy နဲ့ EnemyManager

  EnemyData (models/enemy_data.dart) - ရန်သူတစ်မျိုးရဲ့ data
    image, nFrames, textureSize, speedX, canFly,
    attackable   (ကန်လို့ရလား), points, rocketPoints,
    shootsFire   (မီးလုံးမှုတ်), throwsRocket (ဒုံးကျည်ပစ်),
    deathFrames  (ကန်ခံရရင် ပြမယ့် animation)

  Enemy.update()
    - x -= speedX * dt
    - shootsFire/throwsRocket ဆိုရင် screen ၃၀% ရောက်တာနဲ့ တစ်ခါ ပစ်တယ်
    - screen ကျော်သွားရင် removeFromParent()
  Enemy.transformEnemy()  ကန်ခံရရင် death animation ပြောင်းတယ်

  EnemyManager
    - Timer(2s) တိုင်း spawnRandomEnemy()
        ရမှတ် 500 ကျော်ရင် Pixel Adventure ရန်သူတွေ + skeleton ပါ ပါလာတယ်
    - Milestone ရန်သူများ (_MilestoneEnemy)
        100 တိုင်း မီးမှုတ်တဲ့ ဝက်
        200 တိုင်း ဒုံးကျည်ပစ်တဲ့ ကြက်   (1.5s နောက်ကျ)
        300 တိုင်း ဒုံးကျည်ပစ်တဲ့ လင်းနို့ (3s နောက်ကျ)
        တစ်ပြိုင်နက် ရောက်ရင် (ဥပမာ 600) မထပ်အောင် delay ထားတယ်
    - autoSpawn: false ဆိုရင် (tutorial) ကိုယ်တိုင် spawn မလုပ်ဘဲ
      spawnById('angry_pig') လို ခေါ်မှ spawn လုပ်တယ်

8.5 Collectible များ (collectibles.dart၊ helper_bat.dart)

  Collectible (abstract)
    - မြေပြင်အရှိန်နဲ့ ဘယ်ဘက်ရွေ့တယ်

    - 400 တိုင်း HelperBatItem

9. Gameplay Logic
--------------------------------------------------------------------------------

9.1 ရမှတ်နဲ့ ဆုလာဘ်များ (PlayerData.currentScore setter)

  ရမှတ် ပြောင်းတိုင်း setter ထဲမှာ —
    - x2 ဖြစ်နေရင် တိုးတဲ့ ရမှတ်ကို နှစ်ဆ လုပ်တယ်
    - 20 ရဲ့ အဆ ကျော်သွားတိုင်း rockets +1 (maxRockets ထိ)
    - 200 ရဲ့ အဆ ကျော်သွားတိုင်း bursts +1 (3 ထိ)
    - highScore ထက်ကျော်ရင် highScore ကို update
    - notifyListeners() + save()

  ရမှတ် ရပုံ
    - ရန်သူကန်ရင် enemyData.points (ပုံမှန် 5)
    - ဒုံးကျည်/bomb နဲ့ ပစ်ရင် rocketPoints ?? points
    - စိန်တစ်လုံး 1

9.2 အသက် (lives)

  - စစချင်း 5 (+ maxLives upgrade)၊ တစ်ဝက်ချင်း လျော့လို့ရတယ် (double)
  - HUD မှာ _Heart(fill: 1 / 0.5 / 0) နဲ့ ပြတယ်
  - 0 ရောက်ရင် NinjaRun.update() က GameOverMenu ပြတယ်
  - Revive ဈေး = 20 × 2^revives (20, 40, 80 ...)

9.3 ကာကွယ်မှုများ

  - ဒိုင်း (shieldCharges): ထိခိုက်မှု တစ်ခါကို ကာပြီး 1s မထိခိုက်ဘူး
  - Bat ချီထားချိန်: ဘာမှ မထိခိုက်ဘူး၊ ပြန်ကျပြီး 1s မထိခိုက်ဘူး
  - Revive ပြီးချိန်: 1s မထိခိုက်ဘူး

9.4 ခက်ခဲမှု မြင့်လာပုံ

  ရမှတ်များလာရင် milestone ရန်သူ (မီးမှုတ်၊ ဒုံးကျည်ပစ်) တွေ ပေါ်လာပြီး
  500 ကျော်ရင် ရန်သူအမျိုးအစား ပိုများလာတယ်။

    doubleScoreTime, carryTime, revives

    - HiveField နံပါတ် အသစ် (ရှိပြီးသား နံပါတ်ကို မပြောင်းရ)
    - read() မှာ `fields[n] as Type?` (nullable - data ဟောင်းမှာ မပါလို့)
    - write() မှာ writeByte(field အရေအတွက်) ကို တိုးပြီး field ကို ရေး

12. HUD Guide နဲ့ Tutorial
--------------------------------------------------------------------------------

12.1 HudGuide (widgets/hud_guide.dart)

  ပြတဲ့အချိန်: settings.hudGuideSeen == false နဲ့ highScore == 0 (player အသစ်)
  startGamePlay()/startTutorial() က _showHudGuideIfNew() ကို ခေါ်တယ်။
  Hud ကို add ပြီးမှ ခေါ်ရတယ် (Hud ရဲ့ အပေါ်မှာ ပေါ်ဖို့)။

  လုပ်ပုံ
    1. Engine ကို pause လုပ်ထားတယ်
    2. အဆင့်တစ်ခုစီမှာ Hud.xxxKey နဲ့ widget ရဲ့ RenderBox ကို ရှာပြီး
       နေရာ (Rect) ကို တိုင်းတယ် (post frame callback)
    3. _SpotlightPainter က screen ကို မှောင်ပြီး အဲဒီ Rect ကို
       အပေါက်ဖောက် + အဝါဘောင် ဆွဲတယ်
    4. ရှင်းပြချက် card ကို target အပေါ်ပိုင်းဆို အောက်မှာ၊
       အောက်ပိုင်းဆို အပေါ်မှာ ထားတယ်
    5. ပြီးရင် hudGuideSeen = true, resumeEngine()

12.2 Tutorial (game/tutorial.dart)

  TutorialStep: jump → doubleJump → dodge → kick → diamonds →
                rocket → shield → done

  TutorialManager.update()
    - lives လျော့ရင် ချက်ချင်း ပြန်ဖြည့်တယ် (ဘယ်တော့မှ မရှုံးဘူး)
    - လက်ရှိ step ပြီးမပြီး စစ်တယ်
        jump       ninja မြေပြင်ပေါ်က လွတ်သွားရင်
        doubleJump jumpCount == 2
        dodge      ဝက် screen ကျော်သွားပြီး ထိမခံရရင်
        kick       gino ကို ကန်လိုက်ရင် (isTransformed)
        diamonds   စိန် ၃ လုံး ကောက်မိရင်
        rocket     ဝက်ကို screen ထဲမှာ ဖြိုလိုက်ရင်
        shield     ဒိုင်းရရင်
    - ပြီးရင် _complete(): "တော်လိုက်တာ!" ပြပြီး 1.5s နောက် နောက်တစ်ဆင့်
    - လွဲရင် _retry(): "ထပ်ကြိုးစားပါ" ပြပြီး ပြန် spawn လုပ်တယ်

  state (ValueNotifier) ကို Hud ထဲက _TutorialBanner က နားထောင်ပြီး ပြတယ်။
  Tutorial ထွက်ရင် reset() က စိန်နဲ့ highScore ကို မူလအတိုင်း ပြန်ထားတယ်။
